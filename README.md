# Personal Expense Tracker

A beginner Python project that records personal expenses, analyses spending patterns and generates automated spending reports.

## Project Overview

This project was developed to practise Python programming and introductory data analysis. It allows users to record expenses, organise transactions and understand their spending habits.

## Features

- Record expenses with names, categories and amounts.
- Store transactions in CSV format.
- Calculate total and average expenditure.
- Analyse spending by category.
- Identify the highest-spending category.
- Generate spending percentages.
- Visualise spending using bar charts and pie charts.
- Generate automated spending insights.

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV

- Lists and dictionaries
